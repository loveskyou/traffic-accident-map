# 탐색 호출 결과 (2026-09-27)

`python -m pipeline.collect --probe` 68회 호출. 원본 보고서는 `raw/probe_report.json`(git 제외).

1. **요청 변수 이름**: `siDo`, `guGun` 그대로 동작. 서울 강남구 20건 모두 결과 코드 00 또는 03. 10(요청변수 오류)은 없음.
2. **totalCount 위치**: 응답 최상위. 최상위 키는 `items, numOfRows, pageNo, resultCode, resultMsg, totalCount`. 코드 수정 불필요.
3. **결과 1건일 때 모양**: `items.item`이 목록(list)으로 옴(서울 강남구 보행어린이 2021, 1건). 객체로 오는 경우 처리 코드는 그대로 둠.
4. **항목 필드**: `afos_fid, afos_id, bjd_cd, caslt_cnt, dth_dnv_cnt, geom_json, la_crd, lo_crd, occrrnc_cnt, se_dnv_cnt, sido_sgg_nm, sl_dnv_cnt, spot_cd, spot_nm, wnd_dnv_cnt`. 결빙도 `occrrnc_cnt`(문서의 `occrmc_cnt`는 오타).
5. **코드 전환 시점**:
   - 강원 원주: 2021은 예전 짝(42-130), 2023·2025는 새 짝(51-130).
   - 광주 광산: 보행자 2021·2023은 예전 짝(29-200)에서 결과.
   - 전남 광양: 일반 2021·2023은 예전 짝(46-230), 2025는 새 짝(12-190).
   - 수집기의 "새 짝 먼저, 없으면 예전 짝" 방식으로 모두 처리됨.
6. **호출 한도**: 인증키 발급현황 페이지 기준 API(유형)마다 하루 2,000회, 활용 기간 2026-09-27 ~ 2028-09-27. 한도 초과 응답 모양은 이번에 보지 못함.

인증키는 개인별 단일 키 하나로 10개 REST API 모두 호출됨. 사이트가 주는 키는 퍼센트 인코딩된 형태(68자)라, 디코딩한 값(64자)을 `config.local.json`에 저장하고 호출 때 다시 인코딩한다.
